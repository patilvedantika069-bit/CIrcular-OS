# Circular OS 

**Circular OS** is a web-based prototype designed to help campuses manage their electronic assets using a **reuse-first approach**. Instead of immediately purchasing new equipment, the system checks existing campus inventory and recommends **transfer, repair, reuse, or recycling**.

##  Key Features

* **Dashboard** – Shows total assets, assets saved from becoming waste, procurement savings, and certified e-waste.
* **Smart Purchase Requests** – Checks existing campus inventory before recommending a new purchase.
* **Asset Transfer** – Identifies idle assets that can be transferred between departments.
* **Repair Recommendations** – Finds equipment that is more economical to repair than replace.
* **E-Waste Management** – Identifies assets suitable for recycling and provides a simulated recycling certification.
* **Asset Tracking** – Displays asset location, condition, utilization, status, and recommended action.
* **Procurement Optimization** – Estimates how much purchasing can be avoided through reuse and repair.

##  How It Works

1. Campus assets are stored in the system with information such as type, department, condition, utilization, and replacement cost.
2. When a department requests equipment, Circular OS checks the existing inventory.
3. The system evaluates available assets and generates a recommendation:

   * **Transfer** an idle usable asset
   * **Repair** an economically repairable asset
   * **Recycle** an asset that is no longer practical to use
   * **Purchase** only when suitable reusable equipment is unavailable
4. The user can approve the generated plan and update the simulated inventory.

##  Technology Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* Responsive web design
* Client-side simulated campus inventory

##  Prototype

The current prototype uses simulated campus data and operates entirely in the browser. Data is reset when the page is refreshed.

##  Goal

The goal of Circular OS is to demonstrate how institutions can reduce unnecessary procurement, extend the useful life of electronic equipment, improve asset utilization, and support responsible e-waste management.

##  Impact

Circular OS promotes a **reuse-before-purchase** mindset by connecting underutilized assets with departments that need them. This can help reduce unnecessary spending, extend equipment lifecycles, and reduce electronic waste.
